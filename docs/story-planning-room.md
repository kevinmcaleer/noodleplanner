# User Story: Planning Room and Rooms Navigation

## Story
As a user, I want to select a project from my project list and enter a planning room, so I can add products to the selected project and view all products linked to it. I want to easily switch between different rooms (pages/tabs) using a navigation bar.

## Acceptance Criteria
- There is a navigation bar with selectable rooms (e.g., Projects, Planning).
- When a user selects a project, they are taken to the planning room for that project.
- In the planning room, the user can view project details and a list of products linked to the project.
- The user can add new products to the selected project.
- Only products for the selected project are shown in the planning room.
- Navigation between rooms is seamless and intuitive.

## Notes
- The backend should support fetching project details and products, and adding new products to a project.
- The UI should clearly indicate the current room and selected project.
