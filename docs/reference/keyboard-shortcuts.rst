Keyboard Shortcuts Reference
=============================

Press ``?`` at any time in NoodlePlanner to open the keyboard shortcuts help modal.

Editor Shortcuts
-----------------

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Shortcut
     - Action
   * - ``Ctrl+Enter`` / ``Cmd+Enter``
     - Render the plan
   * - ``Tab``
     - Indent selected task(s) by one level
   * - ``Shift+Tab``
     - Outdent selected task(s) by one level

Navigation Shortcuts
---------------------

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Shortcut
     - Action
   * - ``1``–``9``
     - Switch between the numbered tabs/views
   * - ``Esc``
     - Close the open detail pane or modal

Global Shortcut
----------------

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Shortcut
     - Action
   * - ``?``
     - Open the keyboard shortcuts help modal

File Operations
----------------

Drag and drop a ``.md`` or ``.txt`` file onto the editor area to load it. The file contents replace the current editor text and the plan renders automatically.
