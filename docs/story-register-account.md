# User Story: Register New Account

## Story
As a new user, I want to register for an account so that I can log in and use the planning tool.

## Acceptance Criteria
- There is a registration page accessible from the login page.
- Users can enter a username, full name, and password to create an account.
- Registration fails if the username is already taken.
- After successful registration, the user is redirected to the login page with a success message.

## Notes
- Passwords should be stored securely (hashed, not plain text).
- Registration should validate required fields and provide helpful error messages.
