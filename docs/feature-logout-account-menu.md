# Feature: Logout Button and Account/Profile Menu

## Description
Add a logout button to the top right of the application interface. This button will allow users to securely log out of their session. In the future, this area will also provide access to account and profile management features.

## Tasks
- [ ] Add a logout button to the top right of the UI
- [ ] Connect the button to the backend logout endpoint
- [ ] Display a confirmation or redirect to the login page after logout
- [ ] Reserve space for future account/profile management options

## Related User Stories
- User can log out from any page
- User can access account/profile management from the same menu (future)

## Notes
- Ensure the logout action invalidates the session/token on the backend
- UI/UX should make it clear where to find account and logout options
