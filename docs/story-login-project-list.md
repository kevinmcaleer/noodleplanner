# User Story: Login Page with Project List

## Story
As a user, I want to log in and see a list of all projects I own, so that I can quickly access and manage my projects after authentication.

## Acceptance Criteria
- User can log in with valid credentials.
- After login, the user is redirected to a page displaying a list of their projects.
- Only projects owned by the logged-in user are shown.
- If the user owns no projects, a suitable message is displayed.

## Notes
- This story is part of the authentication and user dashboard epic.
- Project data is retrieved from the backend after authentication.
