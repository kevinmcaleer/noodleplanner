# User Story: Planning Canvas for Project Breakdown

## As a user
I want to visually arrange products as nodes on a canvas, move them around, and connect them to form a hierarchical breakdown structure for my project.

## Acceptance Criteria
- I can see all products for a project as draggable nodes on a canvas.
- I can move nodes freely to arrange the structure visually.
- Each node has handles (top, middle, bottom) to allow connections to other nodes.
- I can create connections between nodes to represent parent-child relationships (breakdown structure).
- Each product can be a 'group' (logical grouping) or a 'product'.
- The hierarchy flows top to bottom.
- The canvas is accessible from the planning room or a dedicated page.
- Changes to the structure are saved and persist across sessions.
- Only authenticated users can access and modify the planning canvas.
