# Feature: Login Page with Project List

## Description
Implement a login page that authenticates the user and, upon successful login, displays a list of all projects owned by that user. This feature enhances user experience by providing immediate access to relevant projects after authentication.

## Tasks
- [ ] Create a login form for user authentication
- [ ] Implement backend endpoint to fetch projects for the authenticated user
- [ ] Display the list of projects on the dashboard after login
- [ ] Handle cases where the user has no projects
