How to Use the 2-Week Look-Ahead
==================================

The 2-Week Look-Ahead view shows you overdue tasks and tasks starting or finishing in the next 14 days. It is the go-to view for daily standups and weekly status reviews.

Open the Look-Ahead View
-------------------------

Click **Tracking** in the project sub-navigation, then select **Look-Ahead** from the dropdown.

Understanding the Two Sections
--------------------------------

Overdue Tasks (red header)
~~~~~~~~~~~~~~~~~~~~~~~~~~~

Lists all tasks past their due date that are not 100% complete.

Columns:

- **Task Name** — the task title (indented to show hierarchy)
- **Due Date** — when the task was supposed to finish
- **Days Late** — number of days overdue (highlighted in red)
- **Resources** — assigned team members
- **%** — percentage complete
- **RAG** — RAG status indicator

Tasks are sorted by due date (earliest first).

Upcoming Tasks (blue header)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Lists all tasks whose start or finish date falls within the next 14 days.

Columns:

- **Task Name**
- **Start Date**
- **Due Date**
- **Duration**
- **Resources**
- **%**
- **RAG**

Tasks are sorted by start date (earliest first).

Edit a Task
------------

Click any row in either section to open the Task Details panel for that task.

Empty State
-----------

If there are no overdue or upcoming tasks, the view shows:

   ✅ No overdue or upcoming tasks in the next 2 weeks!

This indicates your project is on track or complete.

Portfolio Look-Ahead
---------------------

To see look-ahead data across all projects at once:

1. Click **Portfolio** in the main navigation
2. Click the **Timeline** tab (or check the portfolio sub-navigation)
3. The portfolio look-ahead aggregates overdue and upcoming tasks from all projects

Use the project filter dropdown to focus on a single project.
