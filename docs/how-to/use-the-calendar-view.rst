How to Use the Calendar View
=============================

The Calendar view displays your project tasks on a monthly grid, with tasks positioned by their start and finish dates.

Open the Calendar View
-----------------------

After rendering your plan, click **Calendar** in the project sub-navigation bar.

Navigate the Calendar
----------------------

- Use the **left** and **right** arrows to move between months
- Click **Today** to jump back to the current month
- Tasks spanning multiple days appear as bars stretching across the grid

Read the Calendar
------------------

Each task appears as a coloured bar on the calendar grid:

- **Start date** — the bar begins on this day
- **Finish date** — the bar ends on this day
- **Multi-day tasks** span across the days they cover
- **Milestones** appear as markers on a single day
- Tasks are colour-coded by their RAG status

Click to Edit
--------------

Click on any task bar to open the **Task Details** panel, where you can edit task properties.

.. note::

   The Calendar view is best suited for projects where you want to see how tasks fall across specific dates. For timeline-oriented views, consider the Gantt or Timeline views instead.
