How to Use the Mind Map
========================

The Mind Map view displays your project hierarchy as a radial diagram, with the project at the centre and phases and tasks branching outward.

Open the Mind Map
------------------

After rendering your plan, click **Mind Map** in the project sub-navigation bar.

Navigate the Mind Map
----------------------

- **Pan** — scroll or click and drag on the background to move around the map
- **Zoom** — use ``Ctrl+Scroll`` (or ``Cmd+Scroll`` on macOS) to zoom in and out

Keyboard Shortcuts
-------------------

The Mind Map has its own set of keyboard shortcuts for fast editing:

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Shortcut
     - Action
   * - ``Space``
     - Collapse or expand the selected node
   * - ``Enter``
     - Add a sibling node
   * - ``Insert``
     - Add a child node
   * - ``Arrow keys``
     - Navigate between nodes
   * - ``Delete``
     - Remove the selected node
   * - ``Scroll``
     - Pan the view
   * - ``Ctrl+Scroll``
     - Zoom in or out

Collapse and Expand Branches
------------------------------

Select a node and press ``Space`` to collapse or expand its children. This is useful for focusing on a specific area of the project when the map is large.

Change Branch Colours
----------------------

Right-click on a branch to open the **branch colour picker**. Select a colour to apply it to the branch and all its children. This helps visually separate phases or workstreams.

Copy as Image
--------------

To export the mind map as an image:

1. Click the **Copy as Image** button in the Mind Map toolbar
2. The mind map is copied to your clipboard as a PNG image
3. Paste it into documents, presentations, or chat messages

.. note::

   The Copy as Image feature captures the entire mind map, including any collapsed branches. Expand all branches first if you want the full picture.
