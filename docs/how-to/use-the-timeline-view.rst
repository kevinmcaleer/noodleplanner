How to Use the Timeline View
=============================

The Timeline view shows your project milestones on a horizontal timeline. It is useful for presenting a high-level view of key dates to stakeholders.

Open the Timeline View
-----------------------

Click **Timeline** in the project sub-navigation bar.

Reading the Timeline
---------------------

The timeline shows:

- A horizontal line representing the project duration
- **Milestone markers** as diamonds above and below the line
- **Date labels** at each milestone
- An overall **progress bar** showing percentage complete

Milestones alternate above and below the line so labels do not overlap.

Toggle Phase Markers
---------------------

Check the **Show Phases** checkbox at the top to add phase diamond markers to the timeline alongside milestones.

Enable Detailed Mode
---------------------

Check the **Detailed** checkbox to add rectangular phase blocks above the standard timeline. This gives a Gantt-like view of phase durations directly on the timeline.

In detailed mode:

- Each phase appears as a horizontal bar
- Overlapping phases are stacked in separate rows
- **Completed phases** appear in green
- **In-progress phases** appear in blue shades
- A progress overlay shows the percentage complete within each bar
- Hover over a phase bar to see its name and completion percentage
