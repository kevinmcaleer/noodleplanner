Plan Format Guide

Front Matter (Optional)

  • Add YAML front matter between --- markers
  • Define resources with full names and roles
  • Specify holidays and project manager
---
title: Sample Project
project manager: Kevin
Resources:
- @Alice: Alice Smith, Developer
- @Bob: Bob Jones, Designer
Holidays:
- 2025-12-25
- 2025-12-26
---

Phases and Tasks

  • Phase names start at the beginning of a line
  • Tasks are indented with 2 spaces
  • Format: TaskName @Resource Duration %Complete "Comment"
  • Duration: 3days, 2d, 1week
  • Use * for sequential subtasks
  • Use [depends TaskName] for dependencies
Requirements
  capture requirements @Alice 3days 50% "Interviews"
Design
  Low Level Design @Bob 2days [depends capture requirements]
Build
  develop software @Alice 5days
  * unit testing @Alice 2days
  * integration testing @Bob 1day

Milestones

  • Zero-duration tasks are milestones: 0d
  • Show as diamond markers (◆) in timeline

RAG Status

Automatically calculated based on:

  • Green: Task complete (100%) or not due to start
  • Amber: Behind schedule (progress < expected)
  • Red: Overdue with no progress reported

Export Options

  • ASCII Output: Always shown in terminal format
  • Excel: Task table with RAG colors, milestones, and resource sheets
  • PowerPoint: Visual timeline with phases and milestones

Planning Room Help

Overview

The Planning Room provides a structured workflow for creating project plans with three stages:

  • 1. Outline - Define project structure using YAML
  • 2. Flow - Visualize and map task dependencies
  • 3. Schedule - Generate plan.md with dependencies

Keyboard Shortcuts

Ctrl+S / Cmd+SSave to localStorage
Ctrl+L / Cmd+LAuto-layout flow diagram
Ctrl+G / Cmd+GGenerate plan
Ctrl+Z / Cmd+ZUndo
Ctrl+Shift+Z / Cmd+Shift+ZRedo
Ctrl+Y / Cmd+YRedo (alternative)
EscCancel edge creation

Flow Diagram Modes

  • Pan (✋) - Drag the canvas to navigate
  • Select (👆) - Click to select, drag to reposition nodes
  • Link (🔗) - Click source node, then target node to create edge

Tip: Use mouse wheel to zoom in/out on the flow diagram.

Tip: Ctrl+Click on an edge to delete it.

Outline Format

My Project

- Phase 1: Planning
  - Setup environment 5d @alice
  - Create mockups 3d @bob
    - Design homepage 1d @bob
    - Design dashboard 2d @bob
- Phase 2: Development
  - Build backend 10d @alice
  - Build frontend 8d @bob

Data Persistence

Your Planning Room data is automatically saved to browser localStorage. Use the 📦 Export All button to download all files for backup.

Tips

  • Start with the Outline stage to define your project structure
  • Switch to Flow stage to visualize and add dependencies
  • Use Auto-layout to organize the diagram
  • Generate the plan in the Schedule stage
  • Copy the generated plan to the Editor tab for further refinement
